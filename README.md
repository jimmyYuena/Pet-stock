# 持仓宠物

一个会根据持仓盈亏在可爱小牛和上班熊之间切换的原生 macOS 桌面小组件。平时只显示迷你宠物，双击后才展开持仓界面。

## 产品定位（一句话）

把枯燥的持仓盈亏变成一只有情绪的桌面宠物：上班族不能明目张胆盯盘，宠物替你盯；
赚了帮你炫耀，亏了卖萌安慰——**提供情绪价值是第一优先级**。

## 设计与素材规范（新增素材/界面一律遵守本节）

**风格基准：内置的「行情机器人」（`StockPetMascot`）。**
所有新宠物、新界面元素都向它对齐，具体标准：

1. **可爱风**：圆润轮廓、大眼睛、扁平色块 + 深色描边、少量发光点缀。
   禁止写实、恐怖、凶悍造型（哪怕是"牛市之王"这种主题正确但观感吓人的形象）。
2. **情绪价值优先**：宠物存在的意义是给打工人情绪出口。
   - 赚钱 → 兴奋、庆祝、帮用户"炫耀"（分享卡文案要有梗、有排面）；
   - 亏钱 → 委屈、卖萌、安慰用户，而不是让用户更难受；
   - 平盘 → 打盹、摸鱼，陪伴感。
3. **不限物种**：不一定是牛和熊，任何可爱形象都可以；
   但同一只宠物必须有清晰可辨的"涨/跌/平"三种情绪形态（红涨绿跌配合表情动作）。
4. **画质**：优先 SwiftUI 矢量绘制（无限清晰）或 ≥192px 高清手绘帧；
   **禁止低分辨率像素图放大**（≤64px 的像素素材一律不收）。
5. **动效**：流畅且舒缓，宠物是陪伴不是闹钟。矢量动画用连续插值；
   帧动画每形态 ≥6 帧，播放节奏放慢（待机约 2.4fps、动作约 3.4fps），
   呼吸/浮动用低频正弦（约 0.8Hz），发抖等强动作只做短促分段，避免持续高频晃动。
6. **展示**：宠物商城里每只宠物用实时动画预览，不放静态图。

> 下次挑选/制作素材、改界面之前，先读本节。不符合的素材直接淘汰。

## 技术说明

当前版本使用 SwiftUI 编写，无第三方运行时依赖。

## 直接运行开发版

```bash
./run-dev.sh
```

脚本会编译到隐藏的 `.dev/` 目录并直接启动，不安装到 Applications，也不会生成 DMG。

## 打包 DMG

```bash
./build-native.sh
```

产物固定为 `build/持仓宠物.dmg`。每次构建都会删除旧安装包和临时应用，只保留最新版本；安装时拖入 Applications 即可覆盖旧版。当前构建目标为 Apple Silicon（arm64）Mac。

## Mac App Store 准备

Mac App Store 使用独立于官网 DMG 的沙盒签名流程。仓库已提供：

- `native/StockPet.entitlements`：商店版最小沙盒权限；
- `native/PrivacyInfo.xcprivacy`：隐私清单；
- `build-app-store.sh`：使用环境变量读取证书和描述文件的商店 `.pkg` 构建脚本；
- `APP_STORE_SUBMISSION.md`：App Store Connect、素材授权、审核备注和上传清单。

商店签名资料不得提交到仓库。详细步骤见 [APP_STORE_SUBMISSION.md](APP_STORE_SUBMISSION.md)。

## 0.3.2 功能

- 上传持仓截图作为录入参考
- 手动录入持仓名称、市值与收益率
- 按市值加权计算总仓位收益率
- 默认为可爱风「行情机器人」（矢量绘制、无限清晰）：盈利变红色元气形态，亏损变绿色委屈形态
- 公开发布版提供原创「行情机器人」与两套 CC0 高清皮肤（涨跌机甲、红绿北极熊），全部实时动画预览
- 「晒收益」分享卡：大号收益率 + 当前宠物 + 自动梗文案，一键复制/保存，默认隐私模式只显示百分比
- 宠物尺寸随总收益率平滑变化：0% 为原大小、+10% 为 2 倍、-10% 为 0.5 倍，超过 ±10% 后保持极值
- 小牛随盈利增强开心和跳跃动作，亏损时小熊逐渐缩小并切换委屈表情
- 编辑仓位或触发异动提醒后，宠物立即播放一次强化动作
- 默认仅显示迷你宠物和收益标签
- 按住宠物直接移动，双击宠物展开面板，点击向下箭头收起
- 透明拖动窗口随宠物尺寸同步缩放，悬停显示手掌光标、拖动显示抓握光标
- 使用可爱小牛作为 macOS 应用图标
- 按住迷你宠物任意位置即可拖动
- 鼠标悬停时显示前三大核心仓位及各自收益
- 迷你宠物左上角显示热门资讯通知铃铛
- 通知铃铛下方提供调试图标，点击后在主面板内固定显示当前素材的调试工具
- 应用启动后立即拉取行情和前三大持仓资讯，行情每 30 秒、资讯每 1 分钟后台刷新
- 支持打开、单条隐藏或全部隐藏资讯
- 鼠标悬浮展示市值最大的三个持仓
- 模拟语音与 macOS 系统通知
- 数据仅保存在本机 UserDefaults 中

当前版本通过公开行情接口展示市场数据，不包含 OCR 或交易执行功能。第三方宠物素材来源与使用说明见 `THIRD_PARTY_NOTICES.md`。
