# 持仓宠物

一个会根据持仓盈亏在红牛宠物和绿熊宠物之间切换的原生 macOS 桌面小组件。平时只显示一只约 100px 的小宠物，单击宠物后才展开持仓界面。

## 技术说明

当前版本使用 SwiftUI 编写，无第三方运行时依赖。

## 直接运行开发版

```bash
./run-dev.sh
```

脚本会编译到隐藏的 `.dev/` 目录并直接启动，不安装到 Applications，也不会生成 DMG。

## 打包 DMG

```bash
./build-native.sh
```

产物固定为 `build/持仓宠物.dmg`。每次构建都会删除旧安装包和临时应用，只保留最新版本；安装时拖入 Applications 即可覆盖旧版。当前构建目标为 Apple Silicon（arm64）Mac。

## 0.3.0 功能

- 上传持仓截图作为录入参考
- 手动录入持仓名称、市值与收益率
- 按市值加权计算总仓位收益率
- 盈利显示红色牛宠物，亏损显示绿色熊宠物
- 宠物持续呼吸和眨眼；强盈利时红牛跳跃，强亏损时绿熊发抖
- 编辑仓位或触发异动提醒后，宠物立即播放一次强化动作
- 默认仅显示迷你宠物和收益标签
- 单击宠物展开面板，点击向下箭头收起
- 按住迷你宠物任意位置即可拖动
- 鼠标悬停时显示前三大核心仓位及各自收益
- 迷你宠物左上角显示热门资讯通知铃铛
- 按前三大持仓每 5 分钟刷新相关新闻
- 支持打开、单条隐藏或全部隐藏资讯
- 鼠标悬浮展示市值最大的三个持仓
- 模拟语音与 macOS 系统通知
- 数据仅保存在本机 UserDefaults 中

当前版本不包含 OCR、自动行情和交易功能。
